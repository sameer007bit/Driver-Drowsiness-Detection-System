# Driver-Drowsiness-Detection-System
Driver drowsiness detection system using PyTorch classifies Closed Eyes, Open Eyes, No Yawn, and Yawn. Transfer learning with ResNet18, MobileNetV2, and EfficientNetB0 is applied with data augmentation. Evaluation uses accuracy, F1-score, ROC-AUC, confusion matrix, and t-SNE. MobileNetV2 performs best with 96.65% accuracy.
